# Сервис учета рабочего оборудования

## Назначение
Приложение предназначено для автоматизации процесса учета, выдачи и контроля состояния рабочего оборудования на предприятии. Сервис позволяет отслеживать, какое оборудование доступно, а какое уже выдано сотрудникам.

## Целевая аудитория
Сотрудники IT-отдела, кладовщики, администраторы и менеджеры, ответственные за выдачу и учет материальных ценностей.

## Предметная область
Учет материально-технических ресурсов, управление выдачей инвентаря, контроль состояния оборудования и назначение ответственных сотрудников.

## Основные сущности
- Сотрудник (ФИО, должность)
- Оборудование (название, инвентарный номер, состояние)
- Выдача (факт передачи оборудования сотруднику)
- Состояние (рабочее, требующее ремонта, списано)

## Основные функции
- Проверка доступности оборудования для выдачи.
- Формирование карточки оборудования с основной информацией.
- Процесс выдачи оборудования конкретному сотруднику с проверкой статуса.

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
