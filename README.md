# Сервис учета рабочего оборудования

Консольное приложение для учета оборудования, его выдачи сотрудникам
и контроля состояния. Реализовано на основе объектно-ориентированной
модели предметной области.

## Назначение

Приложение автоматизирует учет рабочего оборудования и позволяет
отслеживать, какое оборудование доступно, а какое выдано сотрудникам.

## Целевая аудитория

Сотрудники IT-отдела, кладовщики, администраторы, менеджеры,
ответственные за выдачу и учет материальных ценностей.

## Предметная область

Учет материально-технических ресурсов, управление выдачей инвентаря,
контроль состояния оборудования и назначение ответственных сотрудников.

## Основные сущности

### Equipment — оборудование

Атрибуты:
- `id` — уникальный идентификатор;
- `name` — название;
- `inventory_number` — инвентарный номер;
- `status` — состояние (Рабочее, Ремонт, Списано);
- `is_available` — доступно ли для выдачи.

Методы:
- `is_available_for_issue()` — проверка доступности;
- `__str__()` — строковое представление;
- `from_data()` — создание из словаря JSON.

### Employee — сотрудник

Атрибуты:
- `id` — уникальный идентификатор;
- `name` — ФИО;
- `email` — адрес электронной почты.

Методы:
- `__str__()`;
- `from_data()`.

### Issuance — выдача оборудования

Атрибуты:
- `id` — идентификатор выдачи;
- `equipment` — объект `Equipment`;
- `employee` — объект `Employee`;
- `issue_date` — дата выдачи;
- `is_returned` — признак возврата.

Методы:
- `return_equipment()` — возврат оборудования;
- `__str__()`;
- `from_data()`.

## Взаимодействие объектов

Объект `Issuance` связывает `Equipment` и `Employee`. Оборудование
не может быть выдано дважды, пока не возвращено. Возврат меняет
состояние объекта `Issuance`, не удаляя его из коллекции.

## Хранение данных

Данные хранятся в JSON-файлах каталога `data/`. При загрузке JSON
преобразуется в объекты `Equipment`, `Employee`, `Issuance`. При
сохранении объекты преобразуются обратно в словари. В `issuances.json`
хранятся идентификаторы `equipment_id` и `employee_id`.
