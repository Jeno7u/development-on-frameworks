# Сервис учета рабочего оборудования

Консольное приложение для учета оборудования, его выдачи
сотрудникам и контроля состояния.

## Возможности

- просмотр и поиск оборудования;
- фильтрация по состоянию;
- проверка доступности оборудования;
- выдача оборудования сотруднику;
- возврат оборудования;
- сохранение данных в JSON-файлах.

## Структура проекта

- `main.py` — точка запуска и меню;
- `equipment.py` — работа с оборудованием;
- `issuance.py` — выдача и возврат оборудования;
- `storage.py` — сохранение и загрузка данных;
- `utils.py` — вспомогательные функции ввода;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Требования

- Python 3.x;
- pytest;
- flake8.

## Установка зависимостей

```
pip install -r requirements.txt
```


## Запуск программы

```
python main.py
```
